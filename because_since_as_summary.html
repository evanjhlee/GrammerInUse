because / since / as 완벽 정리 📚

because = 때문에
since = ~니까 / 그러니까
as = 이래서 / ~해서

세 단어 모두 이유를 나타낼 수 있지만, 이유를 말하는 느낌이 조금씩 다르다.

1. 한눈에 비교

단어기억할 대표 뜻느낌핵심 이미지
because~때문에이유를 직접적이고 강하게 설명❓ 왜? → 이것 때문이야!
since~니까 / 그러니까이미 알고 있거나 자연스럽게 받아들일 이유💡 그렇잖아? 그러니까!
as~해서 / 이래서상황이나 배경을 자연스럽게 제시📌 이런 상황이라서

2. because = 때문에

because는 "왜?"라는 질문에 대한 직접적인 이유를 말할 때 가장 잘 어울린다.

1. I stayed home because it was raining.
→ 비가 왔기 때문에 집에 있었다.
2. She was late because she missed the bus.
→ 버스를 놓쳤기 때문에 그녀는 늦었다.
3. I couldn't sleep because I was worried.
→ 걱정했기 때문에 잠을 잘 수 없었다.
4. He didn't go to school because he was sick.
→ 아팠기 때문에 학교에 가지 않았다.
5. We canceled the picnic because it was too cold.
→ 너무 추웠기 때문에 소풍을 취소했다.
암기: because = ❓ 왜? → 때문에!

3. since = ~니까 / 그러니까

since는 어떤 사실을 전제로 놓고 "그러니까 이렇게 하자 / 이런 결과가 생겼다"라는 느낌으로 사용한다.

1. Since it is raining, let's stay home.
→ 비가 오니까 집에 있자.
2. Since you're tired, you should get some rest.
→ 네가 피곤하니까 좀 쉬어야 해.
3. Since it's late, we'd better go home.
→ 늦었으니까 우리 집에 가는 게 좋겠다.
4. Since you know the answer, please tell me.
→ 네가 답을 알고 있으니까 나한테 알려줘.
5. Since tomorrow is Sunday, we don't have to go to school.
→ 내일이 일요일이니까 학교에 갈 필요가 없다.
암기: since = 💡 그렇잖아? → 그러니까 / ~니까

4. as = 이래서 / ~해서

as는 어떤 상황을 배경처럼 먼저 말하고, 그 결과를 자연스럽게 이어가는 느낌이다.

1. As it was raining, we stayed home.
→ 비가 와서 우리는 집에 있었다.
2. As I was tired, I went to bed early.
→ 피곤해서 나는 일찍 잠자리에 들었다.
3. As it was getting dark, we went home.
→ 어두워지고 있어서 우리는 집에 갔다.
4. As she was busy, I didn't call her.
→ 그녀가 바빠서 나는 전화하지 않았다.
5. As the store was closed, we went somewhere else.
→ 가게가 문을 닫아서 우리는 다른 곳으로 갔다.
암기: as = 📌 이런 상황이래서 → ~해서

5. 같은 상황으로 비교하기

Because it was raining, I stayed home.
→ 비가 왔기 때문에 집에 있었다.
→ "왜 집에 있었어?" → 비 때문이야!
Since it was raining, I stayed home.
→ 비가 오니까 집에 있었다.
→ 비가 오잖아. 그러니까 집에 있었지.
As it was raining, I stayed home.
→ 비가 와서 집에 있었다.
→ 비가 오는 상황이라 자연스럽게 집에 있었다.

6. 최종 암기 공식 🧠

🔴 because → 왜? → 때문에
🔵 since → 그렇잖아? → 그러니까 / ~니까
🟢 as → 이런 상황이라서 → ~해서

7. 주의할 점

이 단어들은 이유 외의 뜻도 있다. 따라서 무조건 한국어 뜻 하나만 외우기보다는 문장 전체를 보고 판단해야 한다.

단어다른 대표 의미예문
since~부터Since 2020, I have lived here. → 2020년부터 나는 여기 살고 있다.
as~처럼 / ~대로Do as I say. → 내가 말한 대로 해라.
as~하면서 / ~할 때As I walked home, I saw Tom. → 집에 걸어가면서 Tom을 봤다.
가장 중요한 결론 ⭐
한국어 뜻을 완벽하게 1:1로 구분하려고 하지 말자.

because = 이유를 딱 설명
since = 그러니까
as = 이런 상황이라서
